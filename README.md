## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Environment Variables

Copy `.env.example` to `.env.local` and fill in the values:

- `AIRTABLE_TOKEN`, `AIRTABLE_BASE_ID`, `AIRTABLE_MEALS_TABLE_ID`, `AIRTABLE_PLANS_TABLE_ID` — Airtable credentials for meal/plan data.
- `SITE_PASSWORD` — password gate. A popup prompts for this before the app is usable. This value must exist in the Vercel project env vars, or the site will reject every password.

## Deploy on Vercel

This repo is linked to [https://cookingplan.vercel.app/](https://cookingplan.vercel.app/) with **auto-deploy**: pushes to the default branch deploy automatically.

To change the site password, update `SITE_PASSWORD` in the Vercel project's Environment Variables (Settings → Environment Variables) and redeploy.
